# infra-active

Assessing the active travel impacts of major transport infrastructure, with a
focus on **severance associated with the Strategic Road Network (SRN) in
England**.

The repo is a [Quarto](https://quarto.org) website built from the
[reproducible-project-template](https://github.com/Robinlovelace/reproducible-project-template)
pattern:

- `index.qmd`: the paper, *Severance, parallels and integration* (updated,
  reproducible, and re-centred on the SRN).
- `srn.qmd`: SRN severance page with descriptive statistics and a simple
  regression estimating suppression of walking and cycling in proximity to the
  SRN, plus an interactive map.
- `R/srn/`: numbered R scripts that download all open inputs and regenerate
  every number, figure, and map tile from scratch.
- `map/`: Svelte + MapLibre web map source, compiled into `docs/`.

## Reproducing

All inputs are open (Open Government Licence / ONS):

| Input | Source |
|---|---|
| SRN centre-lines | [National Highways Network Model (Public)](https://opendata.nationalhighways.co.uk), OGL |
| Method of travel to work, LSOA | Census 2021 TS061, ONS |
| Usual residents, OA/LSOA | Census 2021 TS001, ONS |
| LSOA (2021) boundaries | [ONS Open Geography Portal](https://geoportal.statistics.gov.uk/) |
| Population-weighted centroids | Computed from ONS OA (2021) centroids, per ONS guidance |
| Deprivation | [IMD 2019](https://www.gov.uk/government/statistics/english-indices-of-deprivation-2019), MHCLG |
| Rural-urban classification | ONS OGC, LSOA (2021) RUC |

```bash
# analysis (writes data/derived + figures-srn + map inputs)
Rscript R/srn/01_srn_download.R
Rscript R/srn/02_lsoa_inputs.R
Rscript R/srn/03_exposure_model.R
Rscript R/srn/04_map_data.R

# site (use --no-clean so Quarto keeps docs/map/)
quarto render --no-clean

# interactive map: build the Svelte bundle, then tile the map inputs
cd map && npm ci && npm run build && cd ..
tippecanoe -o /tmp/lsoa.mbtiles -Z6 -z10 --layer=lsoa --drop-densest-as-needed \
  --no-tile-stats docs/map/data/lsoa.geojson
tippecanoe -o /tmp/srn.mbtiles -Z5 -z10 --layer=srn \
  --no-tile-stats docs/map/data/srn.geojson
pmtiles convert /tmp/lsoa.mbtiles docs/map/data/lsoa.pmtiles
pmtiles convert /tmp/srn.mbtiles docs/map/data/srn.pmtiles
```

The PMTiles in `docs/map/data/` (~20 MB) and the full LSOA tables in
`data/derived/` (`lsoa_base.csv`, `lsoa_analysis.csv`) are generated by the
pipeline and intentionally not committed; everything else in `docs/` is
committed and served by GitHub Pages.
